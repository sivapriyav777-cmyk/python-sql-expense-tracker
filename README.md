# Expense Tracker Using Python and SQL

## Project Overview

The Expense Tracker is a beginner-friendly Python application that uses SQLite and SQL to record and analyze daily expenses.

## Technologies Used

- Python
- SQLite
- SQL
- CSV
- GitHub

## Features

- Add new expenses
- View all expense records
- Calculate total spending
- Generate category-wise reports
- Filter expenses by category
- Export expense records to CSV

## Project Structure

- `expense_tracker.py` — Main application
- `database.py` — Database connection and table creation
- `sample_data.sql` — SQL queries and sample records
- `sample_expenses.csv` — Sample expense data
- `requirements.txt` — Dependency information
- `.gitignore` — Excludes local database and generated files

## How to Run

1. Install Python 3.
2. Download or clone the repository.
3. Open a terminal in the project directory.
4. Run `python expense_tracker.py`.
5. Select an option from the menu.

The application creates the SQLite database automatically.
